# Mission Match Helper

## Purpose
Suggest a challenge for the user to complete next.

## Inputs
- Preferred Category
- Challenge Category
- Completion Status

## Scoring

+2 Category Match
+1 Unfinished Challenge

## Example

User Preference: Fitness

Challenge A
- Category: Fitness
- Unfinished
Score = 3

Challenge B
- Category: Study
- Unfinished
Score = 1

Result:
Challenge A is recommended because it has the highest score.

## Ethical Considerations

- Recommendations are based only on challenge information.
- No personal or sensitive data is collected.
- User remains responsible for choosing their activities.
